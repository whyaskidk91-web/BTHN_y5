# BTHN_y5

[![Hippocratic License HL3-MIL-SV](https://img.shields.io/static/v1?label=Hippocratic%20License&message=HL3-MIL-SV&labelColor=5e2751&color=bc8c3d)](https://firstdonoharm.dev/version/3/0/mil-sv.html)

An experimental, biology-inspired neuron that grows its own dendritic branches and learns without backprop.

- Solves XOR with a single neuron (a standard single neuron cannot).
- 2.27× less forgetting than a single standard neuron on a two-region continual-learning task (10 seeds). Early results.
